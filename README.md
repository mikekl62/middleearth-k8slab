# Middle Earth Kuberntes Lab

In my current role as a developer of automation solutions based on VMware Aria Automation I need to prepare myself for the switch to the successor VMware Cloud Foundation (VCF). VCF is a major overhaul of the on-prem cloud stack offering from VMware/Broadcom where vSphere Kubernetes Service (VKS) is a core component. Given the increasingly important role kubernetes have in the automation layer, VCF Automation, and my limited kubernete knowledge some serious upskilling is needed.

This repo is a playground where I keep notes, scripts, manifests and other artfacts used during the build of a kubernetes cluster from scratch.

## Hardware bill of materials

* Raspberry Pi 5, 4 GB (4)
*	64 GB SD card for storage (4)
*	Waveshare PoE hat (4)

## Operating system

* Raspberry Pi OS Lite
